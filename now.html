Redesigned my personal website

I finally did a full makeover of this website.

The previous version was built with Hugo and Gokarna. While I was generally happy with it, I found updating the site and adjusting the nitty gritty details of visuals a bit cumbersome. Now with Claude Code I can engineer new features to the site lightning fast, while still maintaining control over every pixel. Furthermore, I switched to using GitHub pages to deploy the site, which makes the whole process a lot easier.
